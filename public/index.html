Designed for discovery

A clearer window into Arabic entertainment.

Watshasha keeps the experience intentional: relevant Arabic titles, useful metadata, fast cached responses, and IDs that work with the wider Stremio ecosystem.

01

Arabic-first catalogue

Movies and series are selected using Arabic original-language metadata and presented with reliable titles and artwork.

Cross-addon ready

Transparent by design

Metadata, not media hosting.

Watshasha is an open-source catalogue and metadata addon. It does not scrape, proxy, host, or resolve video streams, and it never handles debrid credentials. Playback sources come only from addons each user chooses and configures independently.

Metadata and images are provided by TMDB. Watshasha uses the TMDB API but is not endorsed or certified by TMDB.
